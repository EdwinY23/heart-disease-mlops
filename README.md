# Publicación para GitHub Pages

Esta carpeta se llena cuando se ejecuta `python -m scripts.train` con **el dataset real de 918 registros**.

Después de ejecutar en Colab o Python 3.11, aparecerá `docs/index.html` junto con cuatro visualizaciones en `docs/assets/`. Este sitio presenta los **resultados del experimento**, los nombres **Edwin Yunis y Jairo Serrano**, y las interpretaciones, sin mostrar los bloques de Python.

Para publicar, subir el repositorio a GitHub y configurar Settings → Pages → Deploy from a branch → `main` → `/docs`. Hasta que se haya ejecutado con datos reales, no hay resultados legítimos que publicar.
